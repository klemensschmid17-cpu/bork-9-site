Before you sign

Open this page in Phantom's in-app browser. Connect only the confirmed Creator / Deployer wallet. Keep enough SOL for network rent and the token-metadata protocol fee. This action creates the token and the allocations only; it does not create a pool, take public payments, or promise game rewards.
  1. First upload bork9.json and bork9-logo.svg beside this file on bork-9.com.
  2. Open https://bork-9.com/bork9-launch.html in the Phantom browser.
  3. Connect the Creator / Deployer wallet and approve the single transaction after reviewing it.
  4. Save the mint address and transaction link displayed here. The next step is a separate public liquidity-pool transaction.
